{{/* ---------- postgrid shortcode ---------- */}} {{/* Curate an arbitrary hand-picked set of existing Resources pages into a new page of your own, with your own preamble/description above it -- e.g. "Handout for Event X, 12 May: bring these recordings" -- rather than asking people to self-filter via the Search Resources checkboxes. Complements that search (good for "let me find X"), this is for "here is the set I've already chosen for you" (good for a specific retreat, day, or participant group). The actual filtering/rendering lives in partials/resource-grid.html -- shared with the automatic "Follow-up Resources" grid that appears on past event pages (layouts/posts/events/single.html), so both stay in sync. Category/tag matching is case-insensitive on both sides -- this site's frontmatter uses Title Case (e.g. "Audio", "Deep Ecology"). The pool this draws from is everything under posts/ (News, Events and Resources), so a curated page can pull in a relevant upcoming/past event alongside resources -- use excludecategories="Event" if you only want resources, not events, to show up in a particular grid.
